# Source Code

This folder contains the Python implementation of the HAPS Link-Quality Prediction project.

### Files

- `haps_dashboard_combined.py` – Implements the interactive Streamlit dashboard for visualizing HAPS link quality and prediction results.

- `haps_link_quality_itu_complete.py` – Implements propagation modelling, link-budget calculations, synthetic dataset generation, and Random Forest-based link-quality prediction.
